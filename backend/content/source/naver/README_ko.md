## 사용

ZIP 전체를 압축 해제한 다음 START_HERE.html을 여세요. 원음 MP3, 악보 PNG, MusicXML, 비교용 MIDI가 번호별로 연결됩니다. MIDI는 채보를 재생하는 데이터이며 원음은 Original_clips의 MP3입니다.

MusicXML과 MIDI는 이번 음가 수정을 함께 반영했습니다. Data/transcription_data.json과 note_events.csv의 written_duration·written_rest_after 단위는 4분음표의 1/48입니다.

기존 자동 추정의 범위와 출처는 데이터에 남아 있습니다. 이 묶음은 사용자의 마지막 수정 목록을 반영한 채보 자료입니다.
