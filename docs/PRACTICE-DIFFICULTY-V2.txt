Practice 문제은행과 난이도 v2
2026-11-11 / practice-difficulty-2 / 현재 정책

2026-11-12: 전체 1,937문제 중 Practice 1,550개 / Exam 387개로 고정 분리했다.
아래의 난이도 수치·분포는 분리 전 전체 문제은행 기준이며 공식과 커트라인은 동일하다.
문제 소속과 레이팅 규칙은 EXAM-RATING-V1.txt를 확인한다.

팀원이 먼저 알아야 할 내용

1. Level 1은 조표가 없는 문제만 제공한다.
2. Level 2는 조표가 최대 1개인 문제만 제공한다.
3. 조표가 많다는 이유로 높은 레벨을 강제하지 않는다. 상위 레벨은 음정·리듬·조성감과 조표 부담을 함께 평가한다.
4. 문제 출처나 팀원이 붙였던 단계명은 계산에 사용하지 않는다.
5. 클래식과 Drills의 부분 구간 난이도에는 이 8마디 정책을 적용하지 않는다.

Level 1=취미생 입문, Level 5=기존 중급, Level 9=기존 고급이라는 기준점을 유지한다.
이 조건은 초기 운영 정책이며 실제 학생의 정답률로 검증한 능력 척도는 아니다.
조표가 없다는 조건에는 다장조·가단조·조성 미지정 문제가 모두 해당한다.

v1에서 바뀐 부분

v1은 조표 3개를 최대 1.5점만 보정했고, 실제로 67문제가 Level 1~2에 남았다.
v2는 조표 부담을 강화하고 낮은 단계의 진입 조건을 명시한다.
음정·리듬·조성감으로 계산하는 내용 점수, 커트라인, 원본 악보는 그대로 유지한다.

조표 보정

k = 조표 개수 = abs(fifths)
u = 그 마디의 조표가 영향을 주는 음이름 중 새 음으로 나온 종류의 비율

  마디의 조표 부담 = (2*k + 0.5*k*k) * (0.8 + 0.2*u)
  문제의 조표 보정 K = 위 부담을 실제 마디 길이로 가중평균한 값

예: 올림표 2개라면 F와 C 중 그 마디에서 사용한 음이름의 종류를 센다.
종류의 비율이며 등장 횟수의 비율은 아니다. 임시표로 취소한 음이름도 포함한다.
조표를 적게 사용해도 조성을 유지하는 기본 부담이 남는다는 운영 가정으로 80%를 유지한다.
장조·단조라는 이름만으로 별도 점수를 더하지 않으며 샤프·플랫의 계수는 같다.

조표 개수 | 마디별 보정 범위
0 | 0
1 | 2~2.5
2 | 4.8~6
3 | 8.4~10.5
4 | 12.8~16
5 | 18~22.5
6 | 24~30
7 | 30.8~38.5

최종 점수와 낮은 단계의 진입 조건

  임시 점수 = (내용 점수 + K) * (실제 4분음표 BPM / 기준 4분음표 BPM)
  점수 하한 = 0 (조표 0개), 7.5 (1개), 9.5 (2개 이상)
  최종 점수 = max(임시 점수, 점수 하한)

이 하한은 완전한 8마디 문제에만 적용하고, 템포 보정 후 적용한다.
속도를 낮춰도 조표 1개가 Level 1에, 조표 2개 이상이 Level 2에 들어오지 않는다.
하한이 적용되는 구간에서는 속도를 바꿔도 점수가 같을 수 있다.
레벨을 나중에 덮어쓰는 방식이 아니라 최종 점수에 동일한 커트라인을 적용한다.
상위 레벨 진입을 위한 조표 개수 제한이나 조표별 상위 레벨 하한은 없다.

고정 커트라인

Level 1:  0 <= 점수 < 7.5
Level 2:  7.5 <= 점수 < 9.5
Level 3:  9.5 <= 점수 < 13
Level 4:  13 <= 점수 < 30
Level 5:  30 <= 점수 < 55
Level 6:  55 <= 점수 < 62
Level 7:  62 <= 점수 < 68
Level 8:  68 <= 점수 < 74
Level 9:  74 <= 점수

반올림 전 점수로 분류하고, 정확한 경계값은 높은 레벨에 포함한다.
점수에는 100점 상한이 없으며 시험 채점 점수나 정답률을 뜻하지 않는다.

변경하지 않은 내용 점수

H: 부호 있는 반음 간격의 다양성(Shannon entropy, -12~12 범주)
P: 서로 다른 pitch class 수
C: 표기 조표의 기본 음계 밖에 있는 새 음의 비율
J: 인접한 새 음 사이 절대 반음 간격의 평균
N: 주박당 새 음 수
U: 1 - 최적 장·단조 프로파일 상관(음수 상관은 0으로 제한)
S: 약박에서 시작해 다음 주박을 넘어 지속되는 음 수 / 주박 수
T: 잇단음표인 새 음의 비율
E: 붙임줄로 합친 실제 음 길이의 다양성(Shannon entropy)

A = H + 0.7P
B = 60C + 4J + 8N + 30U
R = 2S + T + E/4
sigmoid(x) = 1 / (1 + exp(-x))

내용 = 38*sigmoid(5*(A-10)) + 38*sigmoid(0.6*(B-50))
       + 19*B/(B+40) + 5*R/(1+R)

붙임줄은 실제 들리는 한 음으로 합친다. 한 마디 분석에는 이전 마디의 음정을 물려주지 않는다.
부분 구간 점수에는 이번 점수 하한을 적용하지 않고 level은 null이다.
주박·조성감 프로파일 등의 세부 규칙은 PRACTICE-DIFFICULTY-V1.txt의 내용 점수 부분을 유지한다.
