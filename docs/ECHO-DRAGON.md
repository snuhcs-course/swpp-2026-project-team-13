# 에코 드래곤 초안

Drill → 에코 드래곤. 서버·로그인 없이 로컬 데모에서도 동작합니다. 기존 YDP Grand Piano 음원을 사용합니다.

## 플레이

1. 레벨맵에서 현재 열린 판을 선택합니다. 한 번호는 한 번의 부름과 대답입니다.
2. **드래곤 듣기**를 누르면 두 음과 내 기준음이 차례로 들립니다.
3. 밝은 후보 건반을 누르면 내 기준음과 선택한 음을 한 쌍으로 미리 듣습니다.
4. **대답하기**로 확정합니다. 정답이면 다음 번호의 판이 열립니다.
5. 오답은 같은 문제에서 재시도합니다. 건반 힌트 또는 내 대답→정답 비교를 사용할 수 있습니다.

다시 듣기와 제출 전 탐색은 자유입니다. 첫 제출 정답 3별, 두 번째 정답 2별, 세 번 이상 또는 힌트 사용 1별입니다. 다시 플레이하면 최고 별 기록을 유지합니다. 진행은 이 기기의 UserDefaults에 저장하며 서버 계정과 공유하지 않습니다. 진행 데이터가 손상되어 읽히지 않으면 기존 데이터를 덮어쓰지 않습니다.

## 평평한 72판 레벨맵

새 음정 등장: 1 단2도, 2 장2도, 7 단3도, 13 장3도, 19 완전4도, 31 트라이톤, 37 완전5도, 43 단6도, 49 장6도, 55 단7도, 61 장7도, 67 완전8도. 사이 번호는 누적 복습이고 68–72판은 전체 범위 복습입니다. 트라이톤은 소리만으로 증4도/감5도를 구분하지 않습니다.

1–4판은 부름과 대답의 기준음이 같습니다. 5판부터 기준음이 달라집니다. 판의 목표 음정은 고정되고 재방문 시 시작음이 달라질 수 있습니다. 답 후보는 최대 4개입니다. 새 음정 안내판은 같은 방향 따라 하기로 소개합니다.

25판에서 **거울 대답**: 같은 간격으로 반대 방향에 답합니다. 25판 상행→하행, 26판 하행→상행, 27판 방향 혼합을 반음·온음으로 익힙니다. 이후 따라 하기와 거울 대답을 판마다 미리 표시합니다. 예: 도→레, 내 기준음 솔 → 따라 하기 솔→라 / 거울 대답 솔→파. 음정은 옥타브까지 포함한 부호 있는 MIDI 차이로 판정합니다.

레벨맵의 **거울 대답 미리 체험**과 **옥타브 미리 체험**으로 잠긴 후반도 바로 확인할 수 있습니다. 체험에서는 진행과 별을 저장하지 않습니다.

## iPad에서 확인할 것

- Drill 카드 진입, 1→2→3판 개방, 앱 종료 후 진행 복원
- 반음·온음의 검은 건반 터치, 기준음과 후보의 표시, 선택 후 미리 듣기
- 오답 재시도와 비교 듣기, 힌트 정답 표시, 최고 별 유지
- 거울 체험에서 상행 부름에 하행으로 답하기
- 옥타브 체험에서 12반음과 11반음 비교
- 소리 재생 도중 도움말·레벨맵·앱 닫기·백그라운드 이동 시 즉시 정지
- 복귀 후 **다시 듣고 계속**, 이어폰 분리·오디오 중단 복구
- iPad 가로/세로와 큰 글자에서 스크롤 및 버튼 접근

## 빌드와 검사

새 Swift 파일은 Xcode의 동기화 폴더에 자동 포함됩니다. 프로젝트 파일을 직접 수정할 필요가 없습니다.

Mac:

```sh
swift test --package-path frontend --filter EchoDragonTests
xcodebuild -project frontend/IPadApp/IPadApp.xcodeproj -scheme IPadApp \
  -destination 'platform=iOS Simulator,name=iPad (A16)' \
  -only-testing:IPadAppTests/EchoDragonIntegrationTests test
```

시뮬레이터 이름은 설치된 기기에 맞춥니다. CI는 기존 frontend 검사에 EchoDragonIntegrationTests를 포함하고 레벨맵·거울 화면 첨부 이미지를 보존합니다. push CI의 `solfege-iPad-install`에서 unsigned IPA를 받아 기존 앱과 같은 Apple 계정·Bundle ID로 Sideloadly 업데이트합니다. 상세 설치는 [WINDOWS-IPAD.md](WINDOWS-IPAD.md)를 따릅니다.

이번 초안은 로컬 퍼즐과 기본 벡터 드래곤입니다. 알 부화·이름 짓기·둥지 수집 연출과 서버 학습 기록은 포함하지 않습니다.
